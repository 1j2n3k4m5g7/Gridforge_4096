# Gridforge 4096

## Description:

It's a simple game where you place/destroy blocks in 16x16x16 (4096 blocks) grid.

## Movement:
WSAD:
  * W - forward
  * S - backward
  * A - left
  * D - right

## Interaction:
* LMB - destroy
* RMB - place

---

RMB - Right Mouse Button

LMB - Left Mouse Button
